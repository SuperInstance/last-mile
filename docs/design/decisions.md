# Design decisions

Append-only. Each entry: date, decision, why, and where it's discussed. If an entry is superseded, add a new one that references it.

| D42 | 2026-10-28 | **Presence mode defaults from PoC A:** conditioned lanes beat point mode at equal compute (presence 5 Hz + lane: 88% acc / 3 spurious flips per agent-min at 300 calls vs point: 83% / 34 flips, and point needs 5× the server batches). Default `s1.presence_hz` 10, `lane.alpha` 1/4, `lane.deadband` 0.10 (≈90.5% / 0.8 flips); **batch the whole squad per call**. Caveat: the stub's errors were independent; real model errors correlate over time, so spike S1 re-measures with d1 | [fleet/05](../research/fleet/05-where-this-leads.md) |
| D43 | 2026-10-28 | **Amends D23:** rolling raw `p[]` is a dead end for actions (PoC A: 56% acc, 93 flips). Actions use **argmax with hysteresis on conditioned lanes**; seeded rolls are for **exploration** (⚙ `s1.explore_temp`, default 0) and for **generation** (procgen grammars). `p[]` is still logged as `ROLL`-shaped records | fleet/05 |
| D44 | 2026-10-28 | **Adaptive lead confirmed (PoC B):** one host-level p99 estimator (N=32 samples, +10 ms margin) gives 99.77% on time at 102 ms mean lead vs fixed-3 at 98.28%; leads rise to 4 ticks only during Wi-Fi storms; per-agent estimators are worse | fleet/05 |
| D45 | 2026-10-28 | **FASTER's safe branch:** every committed `Intent` carries an optimistic plan (may cross fog/unknown cells) plus a **safe branch** (only known-free cells, ending in a stable state such as cover or hold). When an intent expires, is refused or arrives late, the agent takes its own safe branch, not a generic default (refines D26). Paths use integer **Jump Point Search**; corridor choices are gate options; the commit horizon = the scheduling lead | [mit-acl/faster](https://github.com/mit-acl/faster), fleet/05 |
| D46 | 2026-10-28 | **Caches are keyed by world tile + structure hash, never screen tiles** (skins, recognition answers, prerendered tiles) | E1: a follow camera with screen tiles re-keys 68% of tiles per frame; world-anchored, 4.8% and 95.6% LRU hits | fleet/05, poc/tiles |
| D47 | 2026-10-28 | **The trainer's output is questions:** System-2 proposes candidate factors; a **matched-pair blindness probe** (pairs differing only in that factor) shows which gates are missing; when a gated student agrees with a code rule on 100% of held-out cases, code takes over (the dial) | E2: gates 91% vs raw 32% at 50 samples; a missing gate is a permanent ceiling; out-of-space blindness is structural | fleet/05, poc/student |
| D48 | 2026-10-28 | **Procgen is a decision grammar** (WFC/archetype choices as typed decisions + seeded dice), steered by a taste model learned from 👍/👎, with **delta regeneration** of disliked regions under neighbour constraints. M2 prerender-ahead | E3: thumbs-up 60% → 99% from one bit per map; deterministic; region repair 100% success touching 9.4% of the map | fleet/05, poc/grammar |
| D49 | 2026-10-28 | **Gate state is code-computed facts in plain language, never raw grids or spatial arithmetic.** Local member/leader gates default to **d1-3B** on the Thor (:8093); d1-omni-600M only for trivial direct questions after calibration against a stronger model; Jev and clef-flash are teachers/judges. | D53 | 2026-10-29 | **Phase 2 host is complete:** a round played on the ProArt is recorded to `runs/<seed>-<unix_secs>.lml` when it ends or when the window closes, and the same file replays bit-exact in `lm-tools` and is scrubbed by `lm-host --replay FILE`. **A round is recorded once, sealed with `HostLoop::finish`, and the file is the round** — the recorder, the headless runner and the viewer all read the same bytes | A round a person played that cannot be replayed is a demo with extra steps; recording it once and refusing to write it twice keeps one file per round, and the path is printed so the reviewer can point at it | spec §10, plan Task 7 |

| D54 | 2026-10-28 | **tev1** (a local 4.3B decision model on the System One API) is a leader / second-opinion judge: served on the Thor; on the ProArt only offline or as `s1_fallback` if a smaller quant fits beside the renderer | E4: facts → 0.97 / 0.93 / bearing 0.72; but 1.34 s p50 on the 4050 with only 3.1/5.7 GB in VRAM | fleet/08 |

| D55 | 2026-10-28 | **Thinking time is gameplay** (Casey: "that time delay is the game"). Each thinking tier has a price in ticks (reflex 0; d1-3B ≈ 5; Jev ≈ 7; tev1 ≈ 40; cloud System-2 ≈ 100s) and a quality. A thought lands at `asked + measured latency + lead`, applied to a world that has moved on. Agents choose the tier per request (policy: urgent → fast tier, planning → slow tier; budgets price both money and time). The piano roll shows each thought as a bar from ask to landing, and the HUD shows tier choices. Latency estimates per tier come from the RTT estimator, so the game adapts to the real network and GPUs | It turns the never-wait design (D11) into a strategic choice instead of a hidden cost: think fast or think well | E4/E4c latency tables; [phase 3 plan](../superpowers/plans/2026-10-28-m1-phase3-agents.md) |

| D56 | 2026-10-28 | **Agents manipulate their own time-to-cognition ratio** (Casey). The levers are the agent's, set in its harness (`policy.toml`, `gates.toml`) and learnable between rounds: (1) **buy time**: hold or follow the safe branch (D45) while a slow tier thinks; (2) **think ahead**: pre-think likely situations in quiet moments (D31, extended to plans); (3) **ask less**: smaller question packs and tighter facts; (4) **reuse**: the verdict cache (D53); (5) **promote**: repeated good thoughts become reflexes (D25); (6) **delegate**: the leader thinks slowly, members act fast; (7) **pay**: spend budget to jump the queue. New metric beside the model-vs-code dial (D40): ticks of thinking per decision vs the decision quality it bought, per agent and per squad | Extends D55: the delay is the game, and steering it is the skill. Phase 3 Task 5 exposes levers 1–4 and 7; phase 5 measures the ratio and lets the reviewer propose ratio changes; lever 5 is M2 | D55 |

| D57 | 2026-10-28 | **Cognition is priced on three axes: time, money and model size** (Casey: "the money-to-cognition ratio… an additional budget on their cloud use or model-size constraints"). Each tier in the `TierTable` (D55) carries latency (ticks), money (tokens × the exchange rate, D16) and a size class (≤1B, ≤3B, ≤9B, cloud). The **round header sets the economy**: per-role cloud allotments, an optional bonus cloud budget, and per-role size caps (for example members ≤3B, leaders up to cloud). This yields game variants (a poor squad, small minds, a rich leader) that are fair, visible and replayable. Agents optimise quality per tick and quality per dollar inside the caps. New metrics: quality per token and quality per tick, per agent and per squad | Extends D55/D56 from time to money and size; turns budgets from limits into a strategic economy | D16, D55, D56 |

| D58 | 2026-10-28 | **The round's clock is a parameter:** a T-minus time countdown (`time_limit_ticks`), a **token-limit countdown** (the round ends when a squad's or the shared thinking budget is spent; `rules.end_on = time | tokens | both`), or both. The HUD shows whichever clock is running, and agents see their remaining clock in their facts, so strategy shifts with the clock (spend early vs hoard) | Casey: "sometimes it's on a time-minus countdown, other times a token-limit countdown, like my subscriptions" | D16, D55–D57 |

| D59 | 2026-10-29 | **Find hard, check cheap: certificate-carrying decisions.** Expensive minds search; every node verifies. Decisions may carry a short, code-checkable certificate (first ones: the safe branch's known-free cells and the facts key the decision was made on), checked before apply; a failed certificate is a refusal | The decision log is already the certificate of a round and replay its checker (like Lean for proofs); making it per-decision keeps verification cheap however costly the thought. Prompted by the ETH video and Casey's "we bypass the hard parts intuitively" | [fleet/09](../research/fleet/09-find-hard-check-cheap.md) |

| D60 | 2026-10-29 | **First learning target, found by testing from the outside:** after the fairness fix, standing still on a beacon out-scores the default reflex on some seeds (seed 3: 1611 vs 861 when squad 0 freezes at tick 1500), and 67% of 200 rounds end in a draw at the 9000-tick limit. The default reflex leaves beacons it holds to chase or flee. Phase 5's first sealed prediction should target this (a "hold what you have" reflex or block), and phase 5 balancing should tune win_score and time_limit for decisiveness | `lm branch` turned a pinned test into a gameplay discovery; this is exactly the loop the game is about | fairness merge 5595db9 |
