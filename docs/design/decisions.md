# Design decisions

Append-only. Each entry: date, decision, why, and where it's discussed. If an entry is superseded, add a new one that references it.

| # | Date | Decision | Why | Ref |
|---|---|---|---|---|
| D1 | 2026-10-28 | Engine: **Bevy (Rust)** | Code-first ECS, precise memory control, and the user prefers it | brainstorm |
| D2 | 2026-10-28 | Visual target: **retro-modern**: low-poly, vertex colors, shared palette, ~640×360–960×540 internal resolution upscaled | Fits 6 GB VRAM; hides generative-asset artifacts; spends budget on world scale and agent count | brainstorm |
| D3 | 2026-10-28 | Milestone 1 is a **thin slice through every tier** | The hard problems are at the seams between machines | brainstorm |
| D4 | 2026-10-28 | **2–4 squads × 4 agents**, each squad with a visible leader | Manageable count; squads give the AI a structure and give the network a batching unit | brainstorm |
| D5 | 2026-10-28 | Human is an **embodied squad member** (any role, not necessarily the leader) or a **spectator** (free camera / drone view) | The human can learn the game in a support role | brainstorm |
| D6 | 2026-10-28 | Talk within squads is the **core mechanic**; rounds form a **learning loop** | Squads learning to communicate is the game | research/05, 09 |
| D7 | 2026-10-28 | Normal mode: between-round changes go through a **sandboxed, hot-reloaded scripting layer**. **Studio mode** (A/B test and vibe-code anything) is a separate mode. | Rules stay fixed within a round so learning and scoring mean something | research/06 |
| D8 | 2026-10-28 | **The MIDI principle:** a stream of performances (decisions) separate from rendering; agent = channel, action = note, round log = score, General Action Set | Tiny stream, renderer-independent, LOD for free, DAW tooling as a bonus | research/07 |
| D9 | 2026-10-28 | Native binary protocol that **mirrors MIDI semantics**; not MIDI UMP on the wire. Real MIDI only at the edges (controllers, `.mid` export). | Payloads are semantic; MIDI's field widths don't fit | research/02, 07 |
| D10 | 2026-10-28 | **Only decisions travel; deterministic lockstep sim on every node; fixed-point math in the core** | Verified in the MIDI Maze source: 1 joystick byte per player per tick. Fixed point avoids x86/ARM float divergence. | research/08 |
| D11 | 2026-10-28 | **AI decisions are scheduled for future ticks; the sim never waits** (late → reflex fallback) | Lockstep's fatal flaw was the slowest node stalling everyone | research/08 |
| D12 | 2026-10-28 | **Utterance = score**: words timed against tone tracks (pitch, energy, rate, emphasis, pauses), plus intent and affect tags | Lossless nuance between agents; the human's tone is captured too; tone can be learned | research/09 |
| D13 | 2026-10-28 | **Agents perceive the score (a physics-filtered view), never pixels**; screens and speakers are for humans | The DAW piano-roll analogy; Thief-style numeric perception | research/10 |
| D14 | 2026-10-28 | **The Thor pre-renders ahead and the 4050 composites**: GI baked into vertex colors, neural vistas, impostor sprites, generated textures; progressive chunk fidelity L0–L3; liked-asset bank on the Orin | EdenLive-class per-frame neural rendering needs a 5090-class GPU | research/10, 11 |
| D15 | 2026-10-28 | **Agents, not bots**: pi-style self-edited harnesses, re-harnessed between rounds; bootstrap harness = situation summaries from the score | The game plays from round 1 and grows from there | research/12 |
| D16 | 2026-10-28 | **Budgets are gameplay**: per-provider token allotments with an exchange table; local models served by a **least-use-first fair-share queue** per round | Subscriptions, not dollars; rewards saving fast thinking for the late round | research/12 |
| D17 | 2026-10-28 | Build approach **A: simulation core first** (shared `lm-core` + `lm-proto`, 2D overhead/piano-roll view, then 3D) | Determinism and replay are correct from day one | brainstorm |
| D18 | 2026-10-28 | **The ProArt is the sequencer and authority**; the Thor and Orin run mirror sims from the decision stream | Human input never waits on the network | brainstorm |

| D19 | 2026-10-28 | **Design philosophy: if more than one option works, make it a parameter** with a default, kept in config or the round header, never a constant | Covers more situations and allows fine-tuning while it runs | user directive |
| D20 | 2026-10-28 | Score format approved: sim tick (default **30 Hz**), min AI scheduling lead (default **3 ticks / 100 ms**), stale-drop window, decision kinds (ActionOn/Off, Control, Program, Utterance, Intent, Marker), state hash interval (default 30 ticks); postcard over QUIC. **All numeric values are parameters (D19).** | Design section 2 | brainstorm |

| D21 | 2026-10-28 | Agent host approved: cognition loop (see → summarize → decide whether to think → least-use-first queue → structured decisions); harness = a git repo per agent on the Thor; **reflexes in Rhai** (no floats, operation-limit fuel) inside `lm-core` on every node, behind a `ScriptRuntime` trait | Design section 3. Rhai is easy for agents to write; WASM can be swapped in later as a parameter | spec §5 |
| D22 | 2026-10-28 | M1 spec written: crates `lm-core / lm-proto / lm-host / lm-agents / lm-router / lm-archive / lm-tools`; default mode "Beacons"; 6 build phases | User asked to keep moving; sections 4–5 folded into the spec | [M1 spec](../superpowers/specs/2026-10-28-last-mile-m1-design.md) |

| D23 | 2026-10-28 | **System-1 rolls dice:** the sim offers a menu of legal decisions; the model returns `p[]`; `lm-core` rolls at `apply_tick` with the seeded RNG; `p[]` is logged in quilt `ROLL` shape | Mirrors agree without trusting the Thor; biased models become visible; replay needs no model | [fleet/02](../research/fleet/02-lessons.md) |
| D24 | 2026-10-28 | Budget exhaustion behaviour is a parameter (`reflex` default, `freeze` as in COLOR SQUAD) | Both are valid game designs | fleet/02 |
| D25 | 2026-10-28 | **The descent:** System-1 decisions are logged with a situation key; N=3 consistent wins → reflex candidate (promoted in M2); reflexes decay or get evicted; **reflex share** is tracked; bark cache | Casey's excavator rubric, from voice-games, voice-reflex-gate and pincher | fleet/02 |
| D26 | 2026-10-28 | **A refusal is an outcome** (no guessed defaults); intents carry a TTL; fixed-point and Rhai golden vectors run on x86 and ARM | thor-firstline's hard-won rules | fleet/02 |
| D27 | 2026-10-28 | The round header pins each agent's harness commit; after the round the harness is tagged `round-<id>` (frozen state) | Learned behaviour replays exactly; rollback unit (saddle) | fleet/02 |
| D28 | 2026-10-28 | Agent audio is half-duplex around the human's push-to-talk; held frames are dropped, not queued | thor-firstline voice gate | fleet/02 |
| D29 | 2026-10-28 | Optional tutor ladder of verbs for the human; negations refused | voice-games; serves D5 | fleet/02 |
| D30 | 2026-10-28 | Downmixing for agent memory and archive: stems for old history, notable events kept verbatim | chrono-tensor §4 | fleet/02 |
| D31 | 2026-10-28 | Squad talk timing: replies pre-drafted while a teammate speaks, airtime budget, silence as a menu option, cadence per agent | quilt-conversation | fleet/02 |
| D32 | 2026-10-28 | Learning judged on held-out eval seeds with sealed predictions; uptake-by-speaker metric; COLOR SQUAD seasons as the M2 template | dungeon-ml-zoo, color-squad, erised | fleet/02 |
| D33 | 2026-10-28 | Between-round human change requests become markdown deposits (said / inferred / machine diff / questions) | moldmaker | fleet/02 |
| D34 | 2026-10-28 | Adaptive scheduling lead from measured p99; the ProArt dials out (WSL NAT); avoid port 8788; wired Thor recommended | Stage 0 LAN weather: Thor paths have an 80–112 ms p99 tail | [fleet/01](../research/fleet/01-measured-facts.md) |
| D35 | 2026-10-28 | Provisional models: members LFM2-1.2B, leaders qwen3.5:9b, between-round operator Qwen3-Coder-30B; optional ProArt 0.6B fallback | Resident on the Thor per Stage 0; the spec sheet may replace them | fleet/01, 02 |
| D36 | 2026-10-28 | last-mile is a **room in the whole-house quilt** (seams, no M1 dependency): `net.sequencer_node` defaults to the ProArt when a human plays and may be the Thor for agent-only rounds; quilt heartbeat; contention classes | Reconciles the quilt's Thor-engine ruling with D18 | [fleet/03](../research/fleet/03-whole-house-quilt-fit.md) |

| D37 | 2026-10-28 | **System-1 = decision models** (Liquid d1, Clef, Jev): state + typed **gates** (bool / choice / score) from harness `gates.toml` → `p[]`; wording comes from a template or a small LLM (`utter.realizer`) | A model class built for the System-1 slot; closed answer sets can't hallucinate an option | [fleet/04](../research/fleet/04-decision-models.md) |
| D38 | 2026-10-28 | **Point vs presence mode:** while the batch latency fits, gates are evaluated at `s1.presence_hz` as control lanes, conditioned in fixed point (EMA + deadband with hysteresis); `auto` falls back to point mode | Casey's "waveform, a presence in the present tense"; replay is unchanged because lane samples are logged decisions | fleet/04 |
| D39 | 2026-10-28 | **Trainer and student:** slow judges (cloud System-2, Clef-27B, the image path) label gate answers; the trainer edits gates; per-role LoRA overnight; challenge seeds; student–teacher agreement on held-out seeds | Distillation with adversarial curricula (not literally a GAN) | fleet/04 |
| D40 | 2026-10-28 | **Building blocks as levels** (`blocks/*.rhai`), chosen and parameterized by gates; the **model-vs-code dial** (signal-chain) generalizes reflex share, with a per-role `dial.target`, not "maximize code" | "Sometimes a calculator, sometimes a storyteller" | fleet/04 |
| D41 | 2026-10-28 | Vision as the second path, looking at **rasters of the score** (map, piano roll, fog view), never the 3D render; off by default, spike first | An alternative angle on the same truth; disagreement becomes a training signal; D13 holds | fleet/04 |

| D42 | 2026-10-28 | **Presence mode defaults from PoC A:** conditioned lanes beat point mode at equal compute (presence 5 Hz + lane: 88% acc / 3 spurious flips per agent-min at 300 calls vs point: 83% / 34 flips, and point needs 5× the server batches). Default `s1.presence_hz` 10, `lane.alpha` 1/4, `lane.deadband` 0.10 (≈90.5% / 0.8 flips); **batch the whole squad per call**. Caveat: the stub's errors were independent; real model errors correlate over time, so spike S1 re-measures with d1 | [fleet/05](../research/fleet/05-where-this-leads.md) |
| D43 | 2026-10-28 | **Amends D23:** rolling raw `p[]` is a dead end for actions (PoC A: 56% acc, 93 flips). Actions use **argmax with hysteresis on conditioned lanes**; seeded rolls are for **exploration** (⚙ `s1.explore_temp`, default 0) and for **generation** (procgen grammars). `p[]` is still logged as `ROLL`-shaped records | fleet/05 |
| D44 | 2026-10-28 | **Adaptive lead confirmed (PoC B):** one host-level p99 estimator (N=32 samples, +10 ms margin) gives 99.77% on time at 102 ms mean lead vs fixed-3 at 98.28%; leads rise to 4 ticks only during Wi-Fi storms; per-agent estimators are worse | fleet/05 |
| D45 | 2026-10-28 | **FASTER's safe branch:** every committed `Intent` carries an optimistic plan (may cross fog/unknown cells) plus a **safe branch** (only known-free cells, ending in a stable state such as cover or hold). When an intent expires, is refused or arrives late, the agent takes its own safe branch, not a generic default (refines D26). Paths use integer **Jump Point Search**; corridor choices are gate options; the commit horizon = the scheduling lead | [mit-acl/faster](https://github.com/mit-acl/faster), fleet/05 |

| D46 | 2026-10-28 | **Caches are keyed by world tile + structure hash, never screen tiles** (skins, recognition answers, prerendered tiles) | E1: a follow camera with screen tiles re-keys 68% of tiles per frame; world-anchored, 4.8% and 95.6% LRU hits | fleet/05, poc/tiles |
| D47 | 2026-10-28 | **The trainer's output is questions:** System-2 proposes candidate factors; a **matched-pair blindness probe** (pairs differing only in that factor) shows which gates are missing; when a gated student agrees with a code rule on 100% of held-out cases, code takes over (the dial) | E2: gates 91% vs raw 32% at 50 samples; a missing gate is a permanent ceiling; out-of-space blindness is structural | fleet/05, poc/student |
| D48 | 2026-10-28 | **Procgen is a decision grammar** (WFC/archetype choices as typed decisions + seeded dice), steered by a taste model learned from 👍/👎, with **delta regeneration** of disliked regions under neighbour constraints. M2 prerender-ahead | E3: thumbs-up 60% → 99% from one bit per map; deterministic; region repair 100% success touching 9.4% of the map | fleet/05, poc/grammar |

| D49 | 2026-10-28 | **Gate state is code-computed facts in plain language, never raw grids or spatial arithmetic.** Local member/leader gates default to **d1-3B** on the Thor (:8093); d1-omni-600M only for trivial direct questions after calibration against a stronger model; Jev and clef-flash are teachers/judges. Each model gets its own confidence threshold; never average models. Supersedes the d1-2B pick in D35/D37 | E4c: d1-3B 0.45 → 0.97 on action with facts instead of the grid; Jev 1.00; bearing (arithmetic) stays in code | [poc/thor](../research/poc/thor/RESULTS.md) |
| D50 | 2026-10-28 | **Network:** keep connections persistent (QUIC/keep-alive) to the Thor's endpoints; recommend Ethernet for the Thor in production | Wi-Fi adds ~12 ms median per call with new connections, and the p99 is ~1 s from connection-setup loss | poc/thor |
