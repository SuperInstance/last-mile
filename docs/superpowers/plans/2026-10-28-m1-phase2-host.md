# last-mile M1 Phase 2 (Host + 2D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo the work is seat-driven: ZCode and MiniMax Code implement, and Claude reviews and commits.

**Goal:** You can **play a round on the ProArt**. A native Windows Bevy app runs the Phase 1 sim as the sequencer and authority. It draws a 2D overhead map and a piano roll, lets the human possess any agent or spectate, records every round to a replayable log, and can open a log and scrub it.

**Architecture:** Two new crates.
- `lm-host-model`: pure logic, no Bevy, tested in WSL. It holds the host loop (sequencer + sim + recorder), input→decision mapping, the map draw model with fog and interpolation, the piano-roll model and the replay scrubber.
- `lm-host`: a thin Bevy 0.20 app that wires those models to the screen. It's built natively on Windows (spec §6).

The sim ticks in `FixedUpdate` at `tick_hz`; rendering interpolates between ticks. **Floats are allowed in both host crates**: they only draw, and never feed back into `lm-core` (D8).

**Tech Stack:** Rust 1.99, `bevy = "=0.20.1"`, `bevy_egui = "=0.43.1"` (panels), plus Phase 1's `lm-core`, `lm-proto` and `lm-tools` (whose runner becomes a library).

**Spec:** [`docs/superpowers/specs/2026-10-28-last-mile-m1-design.md`](../specs/2026-10-28-last-mile-m1-design.md) §6 (ProArt client) and §10 phase 2. Builds on [Phase 1](2026-10-28-m1-phase1-core.md).

## Global Constraints

- Everything in Phase 1's Global Constraints still holds for `lm-core`. **Nothing in this phase may change a Phase 1 golden hash.**
- **The host never decides game outcomes.** Every human action becomes a `Decision { source: Source::Human(agent), provenance: Provenance::Human }` through the same `Sequencer` the agents use (spec §6, D10 lesson 10).
- **Human decisions never wait:** they're submitted with `apply_tick = now` and `arrived = now`, so they're applied on the next simulated tick.
- **Floats are host-only.** Positions are converted to `f32` metres only inside `lm-host-model::map` and `lm-host`, and never converted back.
- **The sim runs at `Params::tick_hz` in `FixedUpdate`, decoupled from the frame rate.** The render interpolates with the fixed-timestep overstep fraction.
- **Windows build:** `lm-host` is built and run with Windows `cargo` from a Windows-side checkout (`C:\Users\casey\src\last-mile`), never across `\\wsl.localhost`. Script: `scripts/win-build.sh`.
- **GPU:** request the high-performance adapter (`PowerPreference::HighPerformance`) so the app runs on the RTX 4050, not the iGPU.
- **Logs go to `runs/`**, which is gitignored: one `.lml` per round, named `runs/<seed>-<unix_secs>.lml`.
- **Commits:** frequent, with conventional prefixes, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The window loses focus or the frame rate drops mid-round:** the sim must keep its tick rate (catching up by running several `FixedUpdate`s), with no skipped or duplicated ticks → test `host_loop_tick_count_matches_elapsed` (Task 2).
2. **Possess an agent, then it's tagged and stunned, or the human releases mid-intent:** inputs while stunned are still recorded (and applied when the stun ends, per Phase 1). Release returns the agent to reflexes with no leftover held action → tests `release_clears_held_action`, `possess_stunned_agent_ok` (Task 3).
3. **Opening a damaged or other-version `.lml` in the replay viewer:** a named error shows in the UI, never a crash → test `scrubber_reports_bad_log` (Task 5).
4. **Scrubbing to tick 0, the last tick, or past the end:** clamp, never panic → test `scrub_clamps` (Task 5).
5. **The ProArt window resized to very small or very large:** the map and piano roll keep their layout (letterbox, scroll) → checked by Task 6's screenshot at 1280×720 and 640×360.

### Task 3: Input → decisions, and possession

**Files:** Create `crates/lm-host-model/src/input.rs`.

**Interfaces:**
- Produces:
  - `InputEvent::{Possess(u16), Release, ClickCell(CellXY), Hold, Spectate, FollowAgent(u16)}`
  - `Viewer::{Spectator { follow: Option<u16> }, Possessing(u16)}`
  - `InputState { viewer: Viewer }` with `apply(&mut self, ev: InputEvent, host: &mut HostLoop) -> Result<(), InputError>`. Mapping:
    - `ClickCell(c)` while possessing a → `submit_human(a, ActionOn(GoTo(c)))`
    - `Hold` → `submit_human(a, ActionOn(Hold))`
    - `Release` → `submit_human(a, ActionOff)`, and the viewer becomes Spectator following a
    - `ClickCell` while spectating → `InputError::NotPossessing`, with nothing submitted

- [ ] **Step 1: Write the failing tests:** `click_while_possessing_moves_agent`, `click_while_spectating_is_refused`, `release_clears_held_action` (after Release, `agent.held == None` at the next tick), `possess_stunned_agent_ok`, `possession_is_recorded_in_log` (the human decisions appear in `log_so_far()` with `Provenance::Human`).
- [ ] **Steps 2–5:** run (FAIL) → implement → run (PASS) → commit `feat(host-model): human input as decisions through the sequencer`.

### Task 4: Map model (fog and interpolation)

**Files:** Create `crates/lm-host-model/src/map.rs`.

**Interfaces:**
- Produces:
  - `MapModel::build(sim: &Sim, prev: &[(u16, Pos)], viewer: &Viewer, alpha: f32) -> MapModel`
  - `MapModel { cells: Vec<(CellXY, CellKind, FogState)>, agents: Vec<AgentDraw>, beacons: Vec<BeaconDraw>, world_m: (f32, f32) }`
  - `AgentDraw { id, squad, pos_m: (f32, f32) /* lerp(prev, cur, alpha) */, facing_rad: f32, stunned: bool, leader: bool, visible: bool }`
  - `FogState::{Visible, Explored, Unknown}`
- **Fog rule:**
  - A **Spectator** sees everything as `Visible`.
  - **Possessing** agent a uses a's squad knowledge: cells are `Explored` if explored, else `Unknown`. Enemies are drawn only if in `last_seen` with `age_ticks == 0`.
  - Teammates are always drawn.

- [ ] **Step 1: Write the failing tests:** `spectator_sees_all_enemies`, `possessed_view_hides_unseen_enemy`, `interpolation_midpoint` (alpha 0.5 between (0,0) and (2 m,0) gives (1.0,0)), `world_size_matches_params` (128 cells × 2 m = 256 m).
- [ ] **Steps 2–5:** FAIL → implement → PASS → commit `feat(host-model): map draw model with fog and interpolation`.

### Task 5: Piano roll and replay scrubber

**Files:** Create `crates/lm-host-model/src/{roll.rs,scrub.rs}`.

**Interfaces:**
- Produces:
  - `RollModel::from_log(log: &RoundLog, events: &[(Tick, Event)], window: Range<Tick>) -> RollModel`
  - `RollModel { lanes: Vec<Lane> }` with one lane per agent in id order
  - `Lane { agent: u16, marks: Vec<Mark>, spans: Vec<Span> }`, where `Mark { tick, kind: MarkKind::{Human, System1, System2, Test, Marker}, late_by: u16 }` and `Span { from, to, what: SpanKind::{Stunned, HoldingBeacon(u8), OnIntent, OnSafeBranch} }`
  - `Scrubber::open(path: &Path) -> Result<Scrubber, LogError>`, `seek(&mut self, tick: Tick) -> &Sim` (replay from 0 to `min(tick, last)`), `len(&self) -> Tick`
  - The host keeps a `Vec<(Tick, Event)>` of live events for the roll.

- [ ] **Step 1: Write the failing tests:** `roll_has_lane_per_agent`, `human_marks_on_possessed_lane`, `stun_span_matches_events` (from a Tagged event at t to a Respawned event at t+90 → `Span(t, t+90, Stunned)`), `scrub_clamps` (seek past the end gives the last tick, seek(0) gives tick 0), `scrubber_reports_bad_log` (a truncated file gives `Err(Truncated)`), `seek_matches_recorded_hash` (seek(900) state hash equals the log's hash at 900).
- [ ] **Steps 2–5:** FAIL → implement → PASS → commit `feat(host-model): piano-roll model and replay scrubber`.

### Task 6: The Bevy app: sim, map, roll, HUD, input

**Files:** Create `crates/lm-host/src/{sim_plugin.rs,map_plugin.rs,roll_plugin.rs,hud_plugin.rs,input_plugin.rs}`. Modify `main.rs`.

**Interfaces:**
- Consumes: everything in `lm-host-model`; the API facts in `docs/notes/bevy-0.20.md`.
- Behaviour:
  - **Sim:** `HostLoop` is a resource stepped in `FixedUpdate` at `tick_hz`. `TickOut` events append to a `LiveEvents` resource.
  - **Map:**
    - cells are drawn once as a batched tile layer, with a fog overlay updated per tick;
    - agents are coloured discs (squad colour, a ring for leaders, grey while stunned);
    - beacons are drawn as diamonds tinted by holder;
    - the camera follows the possessed or followed agent, otherwise it's free (WASD/drag, scroll to zoom).
  - **Roll:** a bottom panel shows the last 300 ticks, one lane per agent, with marks and spans per `RollModel`.
  - **HUD:** a top bar with tick, time left, scores, `SchedStats` (on-time/late/stale) and `SimStats` (reflex fuel, errors, refusals).
  - **Input:**
    - number keys 1–8 possess an agent, 0 or Esc releases;
    - a left click on the map is `ClickCell`, and H is Hold;
    - F follows the hovered agent;
    - Tab toggles between spectator and the possessed view.
